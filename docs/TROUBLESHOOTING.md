# Problemas comuns

| Sintoma | Ação |
| --- | --- |
| Chrome não abre | Instale Google Chrome e confira se está acessível; não reutilize perfil pessoal |
| Perfil ocupado | Use somente uma janela de assistente por runtime; confira a sessão dedicada existente |
| Várias abas do jogo | Deixe apenas a aba desejada no Chrome dedicado e reconecte |
| Senha necessária ou recusada | Corrija Sim/Não e o campo; preserve caixa, símbolos e acentos |
| Ajuda pausada após final | Comportamento esperado; retome quando decidir continuar |
| Janela fecha e Chrome permanece | Comportamento esperado do X; fechar ambos é ação explícita |
| Campo sem resposta | Pode faltar candidato aprovado ou categoria reconhecida; preencha manualmente |
| Tela não reconhecida | Confira aviso no jogo e suspenda ações até retomar com contexto reconhecido |
| Falha gráfica | Execute --verificar-ui e informe sistema/versão; software é o renderer padrão |
| Expulsão por inatividade | Reentre pelo jogo; manter a janela aberta não altera a política do servidor |

Em uma issue, informe versão, sistema, Chrome, formato instalado e passos.
Sanitize logs. Não envie pastas de perfil, cookies, tokens, senha ou endpoint.
