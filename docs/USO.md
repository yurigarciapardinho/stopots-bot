# Usar e controlar a ajuda

## Primeira partida

Abra o aplicativo e mantenha **Só preencher**. Escolha **Escolher no jogo**
para entrar normalmente pelo Chrome ou **Entrar por convite** para usar o
link de uma sala. O assistente acompanha a interface e preenche campos vazios.
STOP, votos, AVALIAR e ESTOU PRONTO continuam manuais nesse perfil.

## Entrar por convite

Cole o link recebido, confira o apelido e indique se a sala tem senha. O código
preserva zeros iniciais. Se houver senha, informe o valor exatamente como
recebido, incluindo maiúsculas, espaços, símbolos e acentos.

Se a sala pedir senha ou recusá-la, o formulário permite corrigir a informação.
O aplicativo não tenta adivinhar a senha. Ela é descartada após a tentativa e
não entra nas preferências ou nos eventos. Restrições impostas pelo jogo são
informadas sem alterar silenciosamente o valor enviado.

## Escolher o perfil

| Perfil | Comportamento |
| --- | --- |
| Só preencher | Preenche campos vazios; os demais controles ficam manuais |
| Só observar | Acompanha a partida sem escrever ou clicar no jogo |
| Automático | Habilita preenchimento, STOP, votos, confirmação da apuração e avanço, respeitando as condições da interface |
| Personalizado | Usa as ações escolhidas nos ajustes |

Expanda o painel para mudar perfil ou permissões. **Aplicando…** indica que
o executor ainda não confirmou a mudança. Os ajustes valem para as próximas
ações; não desfazem texto ou cliques já enviados. Trocar o perfil durante uma
pausa mantém a ajuda pausada.

## Pausar, terminar e continuar

| Ação | Resultado |
| --- | --- |
| Pausar ajuda | Suspende novas ações; o jogo continua disponível para controle manual |
| Retomar ajuda | Faz uma nova leitura da interface antes de agir |
| Fim da partida | Pausa a ajuda e mantém o Chrome aberto |
| X da janela | Encerra a janela e o executor, preservando o Chrome dedicado |
| Reabrir o aplicativo | Reutiliza a sessão dedicada existente, inicialmente pausada |
| Fechar jogo e aplicativo | Fecha explicitamente ambos |

Uma sala pode expirar ou expulsar participantes por inatividade. Manter o
Chrome aberto não altera essa regra. Se houver várias abas do jogo no Chrome
dedicado, deixe apenas a que deseja controlar.

## Atalhos e limites

Com foco na janela: Ctrl+P pausa ou retoma, Ctrl+, abre ajustes e Ctrl+I abre
Sobre. Os controles também estão disponíveis na interface.

O assistente preserva campos já editados. Uma categoria sem candidato pode
ser preenchida manualmente. Na apuração, a ausência de uma palavra no
vocabulário não é suficiente para rejeitar a resposta. STOP depende do botão
habilitado e das condições do perfil; não há um intervalo fixo anunciado para
todas as modalidades.
