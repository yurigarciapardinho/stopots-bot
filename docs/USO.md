# Usar e controlar a ajuda

O perfil inicial é **Só preencher**. Escolha a partida no Chrome ou use convite.
O assistente preenche somente vazios; STOP, votos, AVALIAR e ESTOU PRONTO ficam
com você até autorizar essas ações.

No convite, cole o link, confira o apelido e escolha Sim/Não para senha. Informe
a senha exatamente como recebida. O zero inicial do código é preservado.
Senha necessária ou recusada leva ao formulário para correção; não há tentativa
de adivinhar. A senha é descartada após a tentativa e não é preferência salva.

Expanda o painel para mudar perfil ou ações. **Aplicando…** identifica uma revisão
ainda não confirmada pelo executor. Ajustes afetam próximas ações; não desfazem
as que já foram enviadas. Trocar perfil não retoma uma pausa por conta própria.
Só observar não escreve no jogo. Automático habilita os controles indicados,
mantendo o respeito às fases e aos controles realmente disponíveis.

Pausar mantém o jogo manual. Fim de partida pausa a ajuda. O X encerra a janela
e o executor, preservando o Chrome dedicado. Reabrir observa a mesma sessão,
inicialmente pausada. **Fechar jogo e aplicativo** é a escolha explícita para
fechar ambos. O Chrome pessoal não é alvo de descoberta.

Atalhos com foco: Ctrl+P pausa/retoma; Ctrl+, abre ajustes; Ctrl+I abre Sobre.
STOP respeita sua habilitação real. Ausência no vocabulário não prova erro e
edições manuais são preservadas. Uma sala pode expirar ou expulsar por
inatividade; manter Chrome aberto não altera regras do servidor.
